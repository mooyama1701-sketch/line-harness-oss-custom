# リリースチェックリスト

## 使用方法

- 確認できた項目だけチェックする
- 推測でチェックしない
- alpha、beta、正式版で確認結果を分ける
- リリースごとにチェック結果を見直す

## 正式公開前ブロッカー

- [x] MIT License著作権表示の元作者確認が完了している
- [x] 元OSSの著作権表示とクレジットの同梱方針が決まっている
