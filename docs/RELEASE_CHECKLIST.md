# リリースチェックリスト

## 使用方法

- 確認できた項目だけチェックする
- 推測でチェックしない
- alpha、beta、正式版で確認結果を分ける
- リリースごとにチェック結果を見直す

## 正式公開前ブロッカー

- [ ] 正式なLICENSE本文、または元開発者の許諾を確認している
- [ ] 元OSSの著作権表示とクレジットの同梱方針が確定している

## 1. プロジェクト情報

- [ ] 正式サービス名が決定している
- [ ] GitHubリポジトリ名が決定している
- [ ] npmパッケージ名が決定している
- [ ] バージョン番号が決定している
- [x] 元LINE Harnessの基準バージョンが記録されている

## 2. Git・GitHub

- [ ] Gitの作業ツリーがcleanである
- [ ] 必要な変更がコミットされている
- [ ] mainブランチへ必要な変更が反映されている
- [ ] Gitタグが作成されている
- [ ] GitHub Releaseの内容を確認した
- [ ] 秘密情報が履歴に含まれていない

## 3. 品質確認

- [ ] Lintが成功している
- [ ] 型チェックが成功している
- [ ] 単体テストが成功している
- [ ] ビルドが成功している
- [ ] CLIの基本動作を確認した
- [ ] エラー時の表示を確認した
- [ ] 再実行時の動作を確認した

## 4. Cloudflare検証

- [ ] 新規Workerを作成できる
- [ ] 新規D1を作成できる
- [ ] 新規R2を作成できる
- [ ] 新規Pagesを作成できる
- [ ] D1マイグレーションが成功する
- [ ] Worker Secretsが正しく登録される
- [ ] 同名リソースを無断で上書きしない
- [ ] dev環境だけで検証している

## 5. LINE連携

- [ ] テスト用LINE公式アカウントを使用している
- [ ] Webhookを受信できる
- [ ] 友だち追加イベントを確認した
- [ ] メッセージ受信を確認した
- [ ] LIFFの動作を確認した
- [ ] 本番LINE設定へ影響していない

## 6. セキュリティ

- [ ] 秘密情報がログへ表示されない
- [ ] 秘密情報がGit管理されていない
- [ ] 秘密情報がnpmパッケージに含まれていない
- [ ] 第三者の秘密情報を外部サーバーへ送信しない
- [ ] npm packの内容を確認した
- [ ] 公開対象ファイルを確認した

## 7. ライセンスとドキュメント

- [ ] LICENSEが含まれている
- [ ] 元OSSの著作権表示が維持されている
- [ ] READMEに元OSSのクレジットがある
- [ ] インストール手順が完成している
- [ ] 必要環境が記載されている
- [ ] トラブルシューティングが記載されている
- [ ] サポート範囲が記載されている

## 8. npm公開

- [ ] npmアカウントと権限を確認した
- [ ] npmパッケージ名が利用可能である
- [ ] 正式なLICENSE本文、または元開発者の許諾を確認した
- [ ] package.jsonのversionを確認した
- [ ] npm pack --dry-runを確認した
- [ ] alphaまたはbetaタグを使用した
- [ ] 公開後にnpx実行を確認した

## 9. alpha版

- [ ] 開発者環境で新規構築できた
- [ ] 重大な既知不具合が整理されている
- [ ] alpha版であることを明記している

## 10. ベータ版

- [ ] 第三者による構築テストを実施した
- [ ] テスターからの質問を反映した
- [ ] 初心者向けの説明を改善した

## 11. 正式版

- [ ] ライセンス確認のブロッカーが解消している
- [ ] 正式版の受け入れ条件をすべて満たした
- [ ] v1.0.0として公開可能と判断した
- [ ] 公開後の問い合わせ方法を決定した
